### 🚀 Описание проекта
Изначально проект задумывался как Telegram-бот, однако в рамках архитектурной адаптации под текущие технические условия в РФ, он был полностью **переписан и адаптирован для работы в социальной сети ВКонтакте**.

Бот представляет собой персональный календарь-планировщик с многопользовательским доступом. 

### 🛠️ Технологический стек
* **Язык разработки:** Python 3.x
* **База данных:** PostgreSQL (реляционная СУБД)
* **Библиотеки:** `psycopg2-binary` (работа с БД), `vk_api` / `LongPoll` (взаимодействие с ВК), `Pydantic` (валидация конфигурации)

### 📋 Реализованный функционал (CRUD)
* **Регистрация:** Изолированное создание учетной записи пользователя в СУБД.
* **Create (Создание):** Быстрое добавление заметок через команду `событие`.
* **Read (Чтение):** Просмотр детальной информации о планах.
* **Update (Обновление):** Возможность редактирования даты и описания через команду `изменить` с использованием разделителей `|`.
* **Delete (Удаление):** Безопасное удаление событий из базы по их названию.
