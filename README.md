### 🚀 Описание проекта
Изначально проект задумывался как Telegram-бот, однако в рамках архитектурной адаптации под текущие технические условия в РФ, он был полностью **переписан и адаптирован для работы в социальной сети ВКонтакте**.

Бот представляет собой многопользовательский календарь-планировщик. Вся работа с пользователем построена на **интерактивном кнопочном меню и асинхронной машине состояний (FSM)**, что полностью избавляет пользователя от необходимости вручную вводить сложные текстовые команды.

### 🛠️ Технологический стек
* **Язык разработки:** Python 3.x (Асинхронная архитектура)
* **База данных:** PostgreSQL (Реляционная СУБД)
* **Библиотеки:** `psycopg2-binary` (взаимодействие с СУБД), `vk_api` / `LongPoll` (работа с API ВКонтакте), `Pydantic` (валидация конфигурации и переменных окружения)

### 📋 Реализованный функционал (Продвинутый CRUD + FSM)
* **Автоматическое Главное Меню:** При регистрации бот выдает пользователю постоянную клавиатуру с цветовой индикацией действий.
* **Регистрация:** Безопасное создание изолированной учетной записи пользователя в СУБД PostgreSQL.
* **Create (Пошаговое создание):** Интерактивный мастер создания заметок. Бот предлагает динамические кнопки быстрого выбора даты ("Сегодня" / "Завтра" со скрытым `payload`) и последовательно запрашивает время и название.
* **Read (Чтение):** Вывод списка всех текущих заметок пользователя в чат ВК с автоматической нумерацией строк.
* **Update (Интерактивное изменение):** Логика UX-уровня. Пользователю достаточно выбрать порядковый номер заметки из списка, после чего бот запускает пошаговый процесс обновления параметров (дата, время, название) по уникальному `id` записи.
* **Delete (Удаление):** Безопасное удаление событий из базы данных по их названию с автоматической проверкой прав владельца (`user_id`).
