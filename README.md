# 🍦 Бот-Кафе Мороженого (ВКонтакте + SQLAlchemy 2.0 ORM + SQLAdmin)

Профессиональный бэкенд-проект автоматизации кафе-мороженого, реализованный в виде асинхронного чат-бота ВКонтакте с полноценной веб-панелью управления для администратора.

## 🚀 Архитектурные особенности проекта

Проект спроектирован по стандарту **12-Factor App** и разделен на строгие независимые слои (Three-Tier Architecture):
1. **Слой данных (Models):** Декларативные модели таблиц `User`, `Order` и промежуточная сущность `orders_products` для организации реляционной связи «многие ко многим» средствами асинхронной **SQLAlchemy 2.0 ORM**.
2. **Слой абстракции СУБД (Repositories):** Инкапсулированные классы `UserRepository`, `ProductRepository` и `OrderRepository`. Реализована атомарная асинхронная вставка с обновлением позиций (UPSERT) на базе диалекта PostgreSQL (`on_conflict_do_update`).
3. **Слой бизнес-логики (Services):** Изолированные сервисы `OrderService` и `ProductService`, валидирующие бизнес-правила (контроль дублирования активных заказов, управление статусами сборки корзины).

### Дополнительный функционал:
* **ACL (Access Control List):** Собственная ролевая модель разделения прав доступа (Клиент / Официант) с неблокирующим кэшированием ID персонала в оперативной памяти бота и фоновой синхронизацией с PostgreSQL через асинхронные задачи.
* **Административный интерфейс:** Независимая веб-панель управления на базе **SQLAdmin (Starlette)**, защищенная сессионной UUID-авторизацией.

## 🏁 Инструкция по установке и запуску

### 1. Установка зависимостей (Poetry)
Убедитесь, что у вас установлен менеджер пакетов Poetry. В терминале проекта выполните:
```bash
poetry install
```

### 2. Запуск асинхронного чат-бота ВК
При старте бот автоматически проверит наличие необходимых таблиц в PostgreSQL и создаст их в случае отсутствия:
```bash
poetry run python run.py
```

### 3. Запуск веб-панели администратора (SQLAdmin)
Панель управления запускается как независимый веб-сервер uvicorn на порту, указанном в `.env`:
```bash
poetry run python -m app.admin.main
```
После запуска откройте браузер по адресу: `http://127.0.0.1:8001` и авторизуйтесь под вашими учетными данными администратора.

## 🧪 Сценарии сквозного тестирования в чате

* **Режим Посетителя:** Напишите боту `Старт` ➔ Нажмите `сделать заказ` ➔ Интерактивно соберите корзину через Callback-кнопки меню, подтягиваемые из БД ➔ Нажмите `Завершить заказ` (статус обновится на `ordered`).
* **Режим Официанта:** Напишите `Стать официантом` (роль обновится в СУБД и кэше памяти) ➔ Нажмите `заказы в работе` ➔ Бот выведет состав заказа и инлайн-кнопку выдачи ➔ Кликните `Выдать [номер]` (статус заказа перейдет в `done`).
